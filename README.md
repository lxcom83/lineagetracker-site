# lineagetracker.org

The website for Lineage Tracker: an info page (`index.html`) and an install page (`get.html`). Plain HTML and CSS, hosted free on GitHub Pages at https://lineagetracker.org. The app itself lives in the `Lineage` repository at https://app.lineagetracker.org.

The `CNAME` file tells GitHub Pages to serve this site at lineagetracker.org. Keep it.
